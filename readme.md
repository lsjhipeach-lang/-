# SAPPORO / 4N5D — 여행 협업 대시보드

`index.html`을 열면 바로 실행되는 반응형 여행 컨트롤타워입니다. 별도 빌드 과정은 없습니다.

## 앱 구조

- 대시보드: D-Day, 확정/예약/비용/체크 현황, 5일 마스터 타임라인
- 일정: 날짜별 요약, 상세 편집, 드래그 순서 변경
- 장소: 단풍·맛집·술집 후보, 출처 링크, 투표 및 일정 추가
- 밤 동선: 스스키노 중심 Plan A/B, 도보권 미니 지도
- 통합 지도: 카테고리 필터와 장소 상세
- 운영: 경비, 예약 보드, 출발 전 체크, 최근 수정 내역

## 멤버와 권한

- 이승재: `MASTER` — 전체 편집 및 멤버 관리 권한
- 윤지원: 편집자 — 일정·장소·예약·경비·체크리스트 편집 권한

현재 멤버 전환 버튼으로 두 사용자 화면을 확인할 수 있습니다.

## 데이터 모델

상태는 `script.js`의 `initialData`를 기준으로 하며 다음 컬렉션으로 나뉩니다.

- `schedules`: 날짜, 시간, 장소, 카테고리, 이동·비용·예약·링크
- `foliage`: 평년 단풍 시기와 2026 현장 상태를 분리한 후보지
- `food`, `drinks`: 검증 정보, 우선순위, 투표, 지도·예약 링크
- `reservations`: 상태 보드와 일정 예약 상태 연동
- `expenses`: 공동/개인 구분, 결제자·개인 지출 대상, JPY/KRW 입력값, 환산 금액, 정산 상태
- `checklist`, `activity`: 공식 출처가 연결된 펼침형 준비 항목과 수정 이력

## 저장과 협업 경계

현재 구현은 `localStorage`에 자동 저장하며 `BroadcastChannel`로 같은 브라우저의 여러 탭을 실시간 동기화합니다. 로그인 사용자 간 실제 공동 편집을 배포하려면 `loadState`/`saveState`를 Supabase 또는 Firebase 어댑터로 교체하고, 사용자 인증·행 단위 권한·실시간 구독을 연결해야 합니다. 화면에는 이 제약을 숨기지 않고 공유 모달에 명시했습니다.

## 화면 간 연동

- 공통 환율 → 메인 경비 카드, 경비 통계·내역·정산 원화 금액
- 일정 → 날짜별 보드, 마스터 타임라인, 예상 예산
- 예약 → 연결된 일정의 예약 상태·시간, 메인 예약 통계
- 경비 → 메인 경비, 공동·개인 합계, 1인당 평균, 개인별 실제 부담·정산
- 체크리스트 → 메인 할 일 수·미리보기, 체크 진행률
- 맛집·술집 → 후보 투표, 통합 지도와 스스키노 지도 팝업
- 멤버 전환 → 마스터/편집자 표시와 수정 이력 작성자

앱은 렌더링 후 위 관계의 데이터 무결성을 자동 진단하며 결과를 `body[data-sync-status]`와 `window.tripSyncReport`에 기록합니다.

장소의 2026 영업시간·가격·예약 여부가 검증되지 않은 경우 모두 `확인 필요`로 표시합니다. 미래 단풍과 날씨도 확정 정보로 취급하지 않습니다. 입국·의약품·의류 준비 항목은 일본 디지털청, 일본 세관·후생노동성, JNTO 공식 안내를 연결했습니다.
