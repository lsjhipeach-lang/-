SAPPORO TRIP APP

처음 사용하는 사람을 위한
설치·로그인·연동 안내

데스크톱과 휴대폰에서 같은 여행 일정, 경비, 예약과 체크리스트를 함께 사용하는 방법입니다.

여행 앱 열기빠른 시작
가장 중요한 순서각 기기에서 앱을 먼저 연 다음, 앱 안의 설정 → 서버 로그인에서 이메일 인증번호를 입력하세요. 로그인하기 전에 작성한 내용은 해당 기기에만 저장됩니다.
데스크톱모바일 설치로그인·연동문제 해결
1

빠른 시작

  1. 여행 앱 주소를 엽니다.
  2. 모바일은 홈 화면에 설치하고, 데스크톱은 브라우저에서 바로 사용하거나 설치합니다.
  3. 설정 → 서버 로그인에서 이메일을 입력합니다.
  4. 메일로 받은 가장 최근의 6자리 인증번호를 앱에 입력합니다.
  5. 설정 화면에 이메일 주소가 표시되면 서버 연결 완료입니다.
2

데스크톱에서 사용하기

브라우저에서 바로 사용

  1. Chrome 또는 Edge에서 여행 앱 주소를 엽니다.
  2. 왼쪽 아래 설정 → 서버 로그인을 누릅니다.
  3. 이메일과 6자리 인증번호로 로그인합니다.
  4. 즐겨찾기에 추가하면 다음에 쉽게 열 수 있습니다.

데스크톱 앱으로 설치

  1. Chrome 또는 Edge 주소창 오른쪽의 설치 아이콘을 누릅니다.
  2. 아이콘이 없으면 브라우저 메뉴에서 앱 설치를 찾습니다.
  3. 설치 후 바탕화면이나 시작 메뉴의 앱 아이콘으로 실행합니다.
  4. 설치된 앱에서도 서버 로그인을 한 번 확인합니다.
3

모바일에 설치하기

iPhone · iPad

  1. Safari 또는 Chrome에서 여행 앱 주소를 엽니다.
  2. 브라우저의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택하고 추가를 누릅니다.
  4. 홈 화면에 생긴 삿포로 앱을 실행합니다.
  5. 설치 앱 안에서 서버 로그인을 진행합니다.

Android

  1. Chrome에서 여행 앱 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 앱 설치 또는 홈 화면에 추가를 선택합니다.
  4. 홈 화면의 삿포로 앱을 실행합니다.
  5. 설치 앱 안에서 서버 로그인을 진행합니다.

홈 화면 앱은 브라우저와 로그인 상태가 다를 수 있습니다. 반드시 설치된 앱을 직접 열어 그 안에서 인증번호 로그인을 완료하세요.

4

이메일 로그인과 기기 연동

  1. 앱의 메뉴를 열고 설정 → 서버 로그인을 선택합니다.
  2. 사용할 이메일 주소를 입력하고 인증번호 받기를 누릅니다.
  3. 메일함에서 제목이 삿포로 여행 로그인 인증번호인 최신 메일을 엽니다.
  4. 메일의 6자리 숫자를 원래 앱에 입력하고 인증번호 확인을 누릅니다.
  5. 데스크톱과 모바일 각각에서 같은 과정을 한 번씩 진행합니다.
✓
연동된 상태
설정의 서버 로그인 항목에 이메일이 표시되고, 상태가 서버와 동기화됨으로 나타납니다.
!
연동되지 않은 상태
로그인 전 수정사항은 그 기기에만 남습니다. 여러 기기에서 편집하기 전에 먼저 로그인하세요.
5

연동 확인하기

  • 데스크톱과 모바일 모두 설정에 로그인 이메일이 표시되는지 확인
  • 한 기기에서 체크리스트 항목 하나를 완료 처리
  • 다른 기기에서 같은 변경이 나타나는지 확인
  • 바로 보이지 않으면 화면을 한 번 새로고침하거나 앱을 다시 실행
6

업데이트와 데이터 저장

  • 앱이 수정되어 재배포돼도 다시 다운로드할 필요가 없습니다.
  • 새 버전이 보이지 않으면 앱을 완전히 종료한 뒤 다시 실행합니다.
  • 데스크톱 브라우저에서는 Ctrl + F5로 새로고침할 수 있습니다.
  • 서버 로그인 상태에서는 변경사항이 자동으로 같은 여행 데이터에 저장됩니다.
  • 안전한 미리보기에서 한 변경은 서버에 저장되지 않습니다.
7

문제 해결

인증번호 메일이 오지 않아요.

60초 정도 기다린 뒤 스팸함과 프로모션함을 확인하세요. 재요청했다면 이전 번호가 아니라 가장 최근 번호를 사용합니다.

인증번호가 틀렸다고 나와요.

공백 없이 6자리 숫자만 입력하세요. 이미 사용했거나 새 번호를 다시 요청했다면 기존 번호는 사용할 수 없습니다.

홈 화면 앱이 로그인되지 않았어요.

브라우저에서 로그인한 상태가 설치 앱으로 전달되지 않을 수 있습니다. 홈 화면의 앱을 직접 실행하고 그 안에서 다시 인증번호 로그인을 진행하세요.

다른 기기의 변경이 바로 안 보여요.

두 기기 모두 서버 로그인 상태인지 확인한 뒤 앱을 다시 실행하세요. 인터넷이 끊긴 동안의 변경은 연결이 복구된 후 반영됩니다.

설정 버튼이 보이지 않아요.

메뉴 안쪽을 끝까지 아래로 스크롤하세요. 이전 화면이 남아 있으면 앱을 완전히 종료하고 다시 실행합니다.
