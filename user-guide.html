시작 전에 서버 로그인

여러 기기에서 함께 쓰기

  1. 모바일은 우측 하단 더보기, PC는 좌측 하단 설정을 누릅니다.
  2. 서버 로그인에서 이메일을 입력합니다.
  3. 메일로 받은 가장 최근 인증번호를 입력합니다.
  4. 설정에 이메일과 동기화 상태가 표시되는지 확인합니다.

입력 전 확인

✓
로그인한 기기는 같은 여행 데이터를 함께 사용합니다.
!
안전한 미리보기에서 입력한 내용은 저장되지 않습니다. 실제 계획은 일반 앱 화면에서 작성하세요.
1

Google Maps 장소 불러오기

공유 목록으로 가져오기

  1. Google Maps에서 삿포로 후보를 하나의 저장 목록에 모읍니다.
  2. 목록의 공유 → 링크 복사를 선택합니다.
  3. 설정 → Google Maps 장소 가져오기를 엽니다.
  4. 링크를 붙여 넣고 목록 불러오기를 누릅니다.
  5. 홋카이도 장소인지 확인하고 가져옵니다.

파일로 가져오기

Google Takeout의 CSV·JSON 파일도 같은 화면에서 선택할 수 있습니다. 파일은 현재 기기 안에서만 분석됩니다.

!
위치가 확실하지 않은 장소는 임의의 지도 핀으로 표시하지 않습니다. 가져온 뒤 위치를 확인하세요.
2

장소 분류와 후보 정리

  1. 장소에서 이름·지역·메모로 검색합니다.
  2. 여러 장소를 선택해 식사·술·카페·숙소·쇼핑·관광·이동으로 분류합니다.
  3. 맛집 상세에서 무조건 가기·시간 되면·후보 우선순위를 정합니다.
  4. 주소·위치가 없는 장소를 Google Maps에서 확인해 보완합니다.
  5. 중복 장소를 확인하고 후보를 줄입니다.
✓
분류를 바꿔도 연결된 일정은 유지됩니다. 장소 이름과 지도 링크는 장소 화면에서 한 번만 관리하세요.
3

움직일 수 없는 일정부터 입력

먼저 넣을 일정

  • 항공편 출발·도착
  • 숙소 체크인·체크아웃
  • 이미 예약한 식당이나 투어
  • 시간표가 정해진 버스·열차

입력 방법

  1. 일정 → 새 일정을 누릅니다.
  2. 날짜, 시작 시간, 장소와 체류시간을 입력합니다.
  3. 비용은 1인 금액 / 전체 금액 기준을 선택합니다.
  4. 예약이 있다면 저장 후 예약 추가로 이어갑니다.
✓
시작 시간과 체류시간을 입력하면 종료 시간이 계산됩니다. 종료가 시작보다 이르면 다음 날로 처리됩니다.
4

날짜별 지역을 정하고 장소 배치

  1. 하루의 중심 지역을 하나 정합니다. 예: 삿포로역·오도리·스스키노.
  2. 장소에서 날짜를 선택하고 후보를 검색합니다.
  3. 일정에 추가를 눌러 관광지와 식사를 배치합니다.
  4. 핵심 장소 2~3곳부터 넣고 카페·쇼핑은 여유 시간에 배치합니다.
  5. 같은 날짜에 이미 있는 장소는 기존 일정을 열거나 재방문으로 추가합니다.

장소에 입력

이름, 지역·주소, 지도 링크, 영업시간, 설명과 우선순위

일정에 입력

방문 날짜·시간, 체류시간, 이동방법, 예상 비용과 방문별 메모

5

지도와 확인 항목으로 동선 점검

선택일 지도

  1. 장소에서 날짜를 고릅니다.
  2. 범위를 선택일 일정, 보기를 지도로 바꿉니다.
  3. 방문 순서를 보고 먼 지역이 섞였는지 확인합니다.
  4. 일정에서 종료 시간과 이동시간을 조정합니다.

지도 선은 방문 순서이며 실제 도보·차량 경로는 아닙니다.

홈의 확인할 항목

  • 시간이 겹치는 일정
  • 이동시간이 부족한 구간
  • 연결된 예약이 없는 일정
  • 좌표나 주소가 부족한 장소

항목을 누르면 해당 내용을 바로 수정할 수 있습니다.

6

일정에서 예약 이어서 입력

  1. 예약할 일정을 열고 저장 후 예약 추가를 누릅니다.
  2. 자동 입력된 장소·날짜·시간을 확인합니다.
  3. 예약자, 방법, 번호, 취소 기한과 상태를 입력합니다.
  4. 방문 시간과 예약 시간이 다르면 일정과 다른 예약 시간 사용을 선택합니다.
  5. 예약 관리에서 상태별로 확인합니다.
✓
일정 하나에 예약을 여러 개 연결할 수 있고, 예약 상태는 연결된 일정에도 반영됩니다.
7

예상 비용과 실제 지출 관리

계획할 때

일정에 예상 비용을 입력하고 한 사람 기준인지 전체 기준인지 선택합니다.

식사
1인 ¥2,000
택시
전체 ¥3,000
입장권
1인 ¥1,000

결제했을 때

  1. 일정이나 예약에서 저장 후 지출 추가를 누릅니다.
  2. 자동 입력된 날짜·장소·분류를 확인합니다.
  3. 실제 금액과 결제자를 입력합니다.
  4. 공동·개인·각자 결제 중 하나를 선택합니다.
!
예약 완료만으로 지출이 자동 생성되지는 않습니다. 실제 결제한 뒤 기록하세요.

출발 전 최종 점검

일정

  • 항공·숙소 시간이 정확하다
  • 하루에 먼 지역을 과하게 섞지 않았다
  • 체류·이동시간이 현실적이다
  • 숙소 복귀 방법을 확인했다

장소·예약

  • 방문 장소의 위치가 확인되었다
  • 최신 영업일과 시간을 확인했다
  • 예약번호와 취소 기한을 입력했다
  • 예약 상태가 일정과 일치한다

경비·준비물

  • 환율과 예상 비용을 확인했다
  • 결제 방법을 확인했다
  • 미완료 체크리스트를 확인했다
  • 보험·입국 준비를 마쳤다

공동 사용

  • 두 기기 모두 서버 로그인 상태다
  • 다른 기기에서 변경사항이 보인다
  • 서버 동기화 상태가 표시된다
  • 새 버전이 안 보이면 앱을 재실행한다
